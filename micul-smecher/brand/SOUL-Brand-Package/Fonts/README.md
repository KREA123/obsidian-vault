# Fonts

| Typeface | Use | Download | Licence |
|---|---|---|---|
| **Bricolage Grotesque** | Display, headlines (700/800) and large text (500). The wordmark is cut from it (wght 700, opsz 96). | https://fonts.google.com/specimen/Bricolage+Grotesque | SIL OFL 1.1 |
| **Martian Mono** | Labels, data, captions, the tagline (caps, +40/1000 tracking) | https://fonts.google.com/specimen/Martian+Mono | SIL OFL 1.1 |

Both families are included here as the official Google Fonts variable TTFs (`BricolageGrotesque[opsz,wdth,wght].ttf`, `MartianMono[wdth,wght].ttf`), with their licences (`OFL.txt`). The OFL allows them to be used, embedded and redistributed (not sold on their own).

Web:
```html
<link href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500;12..96,700;12..96,800&family=Martian+Mono:wght@400;500&display=swap" rel="stylesheet">
```

You do not need the fonts to use the logo: every logo file is outlined.
