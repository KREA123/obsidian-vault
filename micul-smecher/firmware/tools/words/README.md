# Keyboard word lists (EN + RO)

`en.txt`, `ro.txt`, `auto.txt` and `next.txt` are the source of
`lib/Suflet/src/WordListData.h` (run `python3 tools/gen_words.py`).

Licence: these lists were written by hand for this project (everyday
vocabulary, ordered by an estimated frequency). They are **not** derived
from FrequencyWords, OpenSubtitles or any other corpus, so they carry no
third-party licence and ship under the firmware's own terms. A real
lexicon (20k words per language, research/04 §15) must come from a
permissively licensed or self-built corpus; FrequencyWords is CC-BY-SA and
cannot be used.
