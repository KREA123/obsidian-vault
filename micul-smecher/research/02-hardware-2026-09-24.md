# Hardware research — Waveshare ESP32-S3-Touch-AMOLED-1.43 and alternatives (raw, 2026-09-24)

Verified against the schematic PDF, V3 demo source, DXF/STEP drawings and raw wiki HTML. **Unverified** where noted. (WebFetch summaries of the wiki garble the pin table — use these values.)

## Six things that affect the design
1. **Two display ICs in circulation:** SH8601 or CO5300. Read register 0xDA: `0x86` = SH8601, anything else = CO5300, which needs a **+6 column offset**. Firmware must handle both.
2. **Charger set to ~2 A** (ETA6098, R23 = 82 kΩ) — 4–5C for a 400–500 mAh cell. Swap R23 to 820 kΩ (0.2 A) / 360 kΩ (0.5 A), or use a bigger cell. Measure.
3. **No power button, no soft power-off.** Battery feeds VCC whenever plugged in. Put a slide switch in the battery lead.
4. **Touch has no INT/RST; no TE pin.** Poll touch; touch cannot wake from deep sleep.
5. **"AMOLED-1.43C" is a different board** (different pinout, audio, PWR key).
6. **VL53L4CD and LTR-303 both use I2C 0x29** — pick VEML7700 (0x10) or move the ToF.

## Electrical (AMOLED-1.43, non-C)
- ESP32-S3R8 (8 MB octal PSRAM) + W25Q128 16 MB flash. Display 466×466 AMOLED, QSPI 40 MHz, RGB565. Touch FT3168. QMI8658 IMU, PCF85063 RTC, MP1605 buck. Native USB (no UART bridge).

| Function | GPIO / addr | Notes |
|---|---|---|
| LCD CS / SCLK | 9 / 10 | |
| LCD SDIO0–3 | 11, 12, 13, 14 | |
| LCD RESET | 21 | |
| LCD TE | none | |
| AMOLED_EN | GPIO42 but R9 NC | panel always on; use SLPIN (0x10) to sleep |

| SD (SPI) | CS 38, MOSI 39, MISO 40, SCLK 41 | |
| BOOT | GPIO0 | no PWR key |
| Free GPIO | 1, 2, 3, 5, 6, 7, 16, 17, 18, 45, 46 | on two 2×7 1.27 mm headers |

- Wake sources GPIO0/8/15 are RTC-capable → ext1 wake-on-motion / RTC alarm possible.
- Power LED always on (~0.85 mA drain on battery).
- Offset from Waveshare `lcd_bsp.c`: `offsetx = (ID == 0x86) ? x : x + 6`. Window x1,y1 even; x2,y2 odd.
- CO5300 init: 11h (80 ms), C4h=80h, 53h=20h, 63h=FFh, 51h=00h, 29h, 51h=FFh. Brightness reg 0x51.
- Demo rotates in software (LVGL 270°); native "up" edge unverified.
- Arduino_GFX v1.6.8: `Arduino_CO5300(bus, rst, r, w, h, col_off1, row_off1, col_off2, row_off2)`; `Arduino_ESP32QSPI(cs, sck, d0, d1, d2, d3)`. Suggested: `Arduino_ESP32QSPI(9,10,11,12,13,14)` + `Arduino_CO5300(bus, 21, 0, 466, 466, 6, 0, ?, 0)`.
- Waveshare demos use esp_lcd + local I2C drivers (legacy `driver/i2c.h`), LVGL 8.4; core ≥ 3.1.0.

## Mechanical (from Waveshare STEP/DXF)
- Cover glass Ø46.00 ±0.1, 1.10 thick (flat front Ø43.0, rounded edge). Touch view Ø36.75.
- Display module ~Ø43.3 (Z 1.1 → 4.0). PCB Ø43.5 × 1.2 (front Z 5.0, back Z 6.2). Back components up to 4.0 → **total stack 10.2 mm**.
- 4 × M2 SMT standoffs (4 mm tall, OD 3.5) at **23.10 × 31.50** (X ±11.55, Y ±15.75).
- USB-C at 9 o'clock (−X), 8.94 × 3.16, face at r = 22.50, centre Z 7.87.
- SH1.0 connectors ~10:30 and 7:30. BOOT/RESET side switches at 12 o'clock (X ±8.03, Z 7.63). microSD at 6 o'clock (edge r ≈ 22.8). FPC wraps at 3 o'clock.
- Battery connector 2-pin 1.25 mm on back ~(+11.5, −8.9) (unverified).
- Files: https://files.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.43/ESP32-S3-Touch-AMOLED-1.43-3DFile.zip
