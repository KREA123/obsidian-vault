# Glosar de lucru

| Termen | Sens în acest document |
|---|---|
| Funnel | Etapele de la expunere la reclamă până la cumpărare, livrare și revenire |
| CRO | Îmbunătățirea experienței pentru a crește rezultatele vizitatorilor eligibili |
| CPA | Cost pe acțiune; trebuie precizat dacă acțiunea este comanda plasată sau altceva |
| CAC | Costul achiziției unui client nou, pe baza de cost definită |
| AOV | Valoarea medie a comenzilor, cu baza de venit explicită |
| ROAS | Venitul atribuit împărțit la costul reclamei |
| MER | Raportul dintre venit total eligibil și cheltuiala totală de marketing |
| Contribuție | Venit minus costuri variabile; nu este profit net |
| CAPI | Transmiterea de evenimente către Meta prin integrare server |
| Retargeting | Publicitate către persoane care au interacționat anterior |
| Incrementalitate | Rezultatul suplimentar produs de intervenție față de absența ei |
| Cohortă | Grup de comenzi sau clienți definit prin aceeași perioadă ori condiție |
| SKU | Referință comercială internă; nu este automat ID-ul catalogului Meta |
| Control | Varianta de comparație păstrată într-un experiment |
